특별 지도가 필요한 학생을 특정 모둠에 고정합니다. 아이들에게 보이지 않아요.

지난 기록 직접 입력
모둠마다 이름을 한 줄에 한 명씩 적어 주세요. 같은 반·같은 달 기록이 있으면 덮어써요.
반 선택 / 추가
사용설명서
1
반 선택 또는 추가
이름입력 카드 맨 왼쪽 드롭다운에서 반을 선택하거나, 학급추가 버튼으로 새 반을 추가하세요.
2
학생 이름 입력
왼쪽 칸에 이름을 한 줄에 한 명씩, 또는 쉼표(,)·탭으로 이어서 입력하세요. 칸 밖을 누르면 "김가영, 김민성, …"처럼 가로로 정리돼요.
엑셀에서 복사해 붙여넣기도 되고, 일괄입력의 ↓(양식 다운로드)·↑(명단 업로드) 버튼으로 파일을 올릴 수도 있어요.
3
모둠 뽑기
모둠을 뽑아주세요! 그림 버튼을 누르면 5초 카운트다운 뒤 대포 소리와 함께 이름이 슬롯머신처럼 돌다가 한 줄씩 공개되고, 마지막 줄은 뜸을 들여 공개돼요. 끝나면 결과가 전체화면으로 뜹니다. 지난 기록을 참고해 겹침을 최소화해요. 중간에 오른쪽 아래 건너뛰기로 바로 결과를 볼 수 있어요.
4
모둠장 지정 (선택)
전체화면 결과 화면에서 학생 이름을 클릭하면 ⭐ 모둠장으로 지정됩니다. 구글 시트가 연결돼 있으면 이름 옆에 모둠장을 한 횟수만큼 노란 ★, 매니저는 파란 ★이 표시돼요.
5
결과 저장
전체화면 결과 상단의 저장하기를 누르면 기록이 보관됩니다. 마음에 안 들면 다시 섞기, 끝나면 닫기로 원래 화면으로 돌아가요.
기록 탭
반별 카드마다 "N월 배치기록"이 나열되고, 보기로 그때 결과를 다시 보거나 삭제할 수 있어요. 카드 위 화살표로 접고 펼쳐요. 체크박스로 여러 건을 골라 인쇄하거나 JPG 저장(파일이름 규칙은 칸에서 바꿀 수 있어요, 기본 "모둠배치-3학년1반9월")할 수 있고, 사라진 기록은 기록 직접 입력으로 손수 다시 넣을 수 있습니다.
소리 버튼
탭 줄 오른쪽의 스피커 버튼으로 뽑기 효과음(북소리·대포·슬롯·팡파르)을 끄고 켤 수 있어요.
열쇠 버튼
특별 지도가 필요한 학생을 특정 모둠에 미리 고정하는 고정 학생 설정이 가능합니다.
추가 기능
구글 로그인
오른쪽 위 구글 로그인 배지로 로그인하면 기록이 구글 계정에 저장되어 다른 기기에서도 동일하게 사용할 수 있어요. 새 컴퓨터에서는 배지가 동기화 완료로 바뀐 뒤에 사용하세요.
구글 시트 연동 (GAS)
오른쪽 위 ☁ 구글 시트 연결 배지를 누르면 구글 앱스스크립트 URL을 연결할 수 있고, 연결하면 모둠 결과와 모둠장 횟수가 구글 시트에 자동 저장됩니다.
